## File connection overview

| File | Role |
|------|------|
| `app/components/ui/Navigation.tsx` | Main navbar; uses `GlassSurface` and `glass-join-beta` |
| `app/components/ui/GlassSurface.tsx` | Glass effect component with SVG displacement |
| `app/components/AppWrapper.tsx` | Renders `Navigation` |
| `app/layout.tsx` | Root layout; wraps app in `AppWrapper` |
| `app/globals.css` | `.glass-join-beta` styles for the Join Beta button |

Dependencies: `framer-motion`, `@studio-freight/react-lenis`, `next/image`, `next/link`.
